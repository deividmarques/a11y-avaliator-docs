Análise WCAG

Teste automático baseado em Web Content Accessibility Guidelines

O que é WCAG?

WCAG (Web Content Accessibility Guidelines) são as recomendações internacionais que guiam como fazer seu site realmente acessível. Criadas pela W3C em parceria com especialistas em acessibilidade.

Pense nela como um "guia de instruções" para não deixar ninguém para trás. A maioria das legislações mundiais se baseia nela.

Os 3 Níveis

Nível A

O Básico - Sem isso, seu site exclui muita gente

  • Imagens precisam descrever o que mostram
  • Vídeos precisam de legendas
  • Páginas têm títulos descritivos
  • Informação não depende só de cores
  • Links são claros e identificáveis

✅ Obrigatório. Nenhuma discussão.

Nível AA

O Alvo - Acessibilidade real para a maioria

  • Texto legível mesmo com baixa visão (contraste 4.5:1)
  • Tudo funciona sem mouse
  • Sempre sabe onde o foco está
  • Descrições de áudio em vídeos
  • Conteúdo organizado logicamente

🎯 Seu objetivo deveria ser chegar aqui. É alcançável e vale muito a pena.

Nível AAA

O Premium - Acessibilidade exemplar

  • Contraste super alto (7:1+) para até enxergados com muita dificuldade
  • Explicações detalhadas de conceitos complexos
  • Nada que pisque rapidamente (causa problemas neurológicos)
  • Linguagem de cada seção está marcada
  • Tudo tem alternativa, não só imagens

Ideal se você trabalha com saúde, governo, educação. Difícil, mas possível.

Como o Plugin Testa WCAG

Este plugin usa axe-core, uma ferramenta gratuita e confiável que verifica automaticamente se seu site segue os padrões WCAG.

Lembrance Importante

Testes automáticos encontram cerca de 50-70% dos problemas reais. O resto você descobri testando com pessoas de verdade usando teclado e leitores de tela. Mas começar por aqui é essencial.

Exemplo de Violação Detectada

Imagem sem alt text (WCAG 2.2 1.1.1 Conteúdo Não-texto)

<img src="logo.png"> <!-- SEM alt -->

Problema: Leitores de tela não sabem o que a imagem representa

Solução: <img src="logo.png" alt="Logo da empresa XYZ">

Nível: A (Obrigatório em todos os níveis)

Exemplo Correto

Imagem com alt text descritivo

<img src="chart.png" alt="Gráfico de vendas 2024: aumento de 25%">

Leitor de tela dirá: "Gráfico de vendas 2024: aumento de 25%"

Categorias de Testes WCAG

Os testes WCAG cobrem 4 princípios:

1️⃣ Perceptível

Usuários devem perceber o conteúdo

  • Imagens com alt
  • Vídeos com legendas
  • Bom contraste
  • Texto redimensionável

2️⃣ Operável

Usuários devem navegar funcionalidade

  • Navegação por teclado
  • Sem keyboard traps
  • Links claros
  • Botões acionáveis

3️⃣ Compreensível

Usuários devem entender conteúdo

  • Idioma da página marcado
  • Instruções claras
  • Formatação consistente
  • Sem jargão

4️⃣ Robusto

Conteúdo deve ser compatível

  • HTML válido
  • Compatível com AT
  • Sem erros críticos
  • Semântica correta
