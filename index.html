📦 Instalação

Chrome Web Store

Instale diretamente da Chrome Web Store:

Adicionar ao Chrome

Instalação Manual

  1. Baixe a última versão em Releases
  2. Extraia o arquivo ZIP
  3. Acesse chrome://extensions/
  4. Ative o "Modo do desenvolvedor"
  5. Clique em "Carregar sem compactação"
  6. Selecione a pasta dist extraída

🚀 Como Usar

1

Abra a página a ser analisada

Navegue até qualquer site que deseja avaliar

2

Clique no ícone da extensão

O popup será aberto com as opções de configuração

3

Configure os testes

Escolha o nível WCAG (A, AA, AAA) e testes adicionais

4

Clique em "Analisar Página"

Os resultados serão exibidos com score e violações detalhadas

✨ Recursos

🎯 Análise WCAG Completa

Validação automática usando axe-core para níveis A, AA e AAA

⌨️ Teste de Teclado

Detecta problemas de foco, tabindex incorreto e keyboard traps

🔊 Teste de Leitor de Tela

Verifica nomes acessíveis, ARIA, landmarks e alt text

🎨 Teste de Contraste

Analisa contraste de cores em textos e elementos interativos

📊 Sistema de Pontuação

Score 0-100 com pesos por severidade e nível WCAG

📄 Exportação

Exporte relatórios em JSON ou PDF detalhado

🔧 API Core (@a11y/core)

O núcleo da lógica de validação foi extraído para um pacote reutilizável:

import { calculateAccessibilityScore } from '@a11y/core';
import { createAxeAnalyzer } from '@a11y/core';

const analyzer = createAxeAnalyzer();
const tags = analyzer.getWcagTags('AA');
const score = calculateAccessibilityScore(result);
