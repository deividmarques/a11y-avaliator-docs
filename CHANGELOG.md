## [0.1.59] - 2025-12-28

### 🔒 Segurança
- **Refatoração crítica para CSP (Content Security Policy)**
  - Eliminada injeção dinâmica de scripts via `document.createElement('script')`
  - Implementado `chrome.scripting.executeScript` com bypass nativo de CSP
  - Agora funciona em sites bancários, governamentais e corporativos com políticas rigorosas

### ✨ Melhorias
- **Arquitetura simplificada**
  - Removido `inpage.js` (não é mais necessário)
  - `content.ts` reduzido de 117 para 31 linhas
  - Comunicação direta via Chrome API (sem `postMessage` com origem `*`)
  
### 📦 Build
- `content.js` otimizado: reduzido de 1.65kB para 0.30kB (82% menor)
- Build limpo: 2 arquivos principais (content + background)
- TypeScript: 0 erros de compilação

### 🧪 Testes
- Configurado Vitest + React Testing Library
- Adicionado coverage com @vitest/coverage-v8
- GitHub Actions: workflows para testes e build automáticos
- Setup de mocks para Chrome API e axe-core

### 🛠️ Infraestrutura
- ESLint moderno configurado (flat config)
- Lint personalizado com mensagem de sucesso
- Script `test:coverage` para relatórios de cobertura
- Pasta `coverage/` adicionada ao `.gitignore`

### 🐛 Correções
- Ordem de versionamento: agora incrementa apenas após build bem-sucedido
- Tipos TypeScript: correções em `axeAnalyzer`, `keyboardTester`, `screenReaderTester`
- Imports organizados alfabeticamente
